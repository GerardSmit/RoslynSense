# Support

Report defects and request features in the
[RoslynSense issue tracker](https://github.com/GerardSmit/RoslynSense/issues).

Include the VS Code version, RoslynSense extension and server versions, operating system, and the
relevant output from **View → Output → RoslynSense** or **RoslynSense Debug**. Protocol captures are
disabled by default and should only be attached after checking them for private source or feed data.
