# Vendored diagnostic-code documentation

`diagnostic-codes.json` is what `DiagnosticCodeCatalog` knows about the code families that document
themselves nowhere a running process can read: NuGet's `NU####` and MSBuild's `MSB####`. Hovering
`NU1605` in a `<NoWarn>` shows what a package downgrade is from this file.

The other families need no table. A `CS####` comes from Roslyn's own `ErrorFacts`, which is the same
resource the compiler builds its descriptor from; a `CA####`, `IDE####` or a third-party rule comes
from the analyzer that defines it, when the project is loaded; and anything else still gets its
documentation URL, which is derivable from the prefix.

## Provenance

Generated by `build-diagnostic-codes.py` from the Microsoft documentation sources:

| Family | Source | Licence |
| --- | --- | --- |
| `NU####` | [NuGet/docs.microsoft.com-nuget](https://github.com/NuGet/docs.microsoft.com-nuget), `docs/reference/errors-and-warnings` | CC BY 4.0 |
| `MSB####` | [MicrosoftDocs/visualstudio-docs](https://github.com/MicrosoftDocs/visualstudio-docs), `docs/msbuild/errors` | CC BY 4.0 |

Regenerate with:

```
python build-diagnostic-codes.py
```

It downloads both sources into a temporary directory and rewrites the JSON in place. Review the
diff: the extraction reads a page's headings, so an upstream page that is restructured goes quiet
rather than wrong, and a code losing its description in the diff is the signal for that.

## What is in it, and what is not

One object per code, all fields optional:

| Field | What it is |
| --- | --- |
| `severity` | `warning` or `error`, as the page titles it. |
| `message` | The text the build prints, with the placeholders the page shows. NuGet pages only. |
| `description` | One or two sentences of explanation — the page's *Issue* or *Description* section, clipped. |

Only codes a build can be told to ignore are kept. Every `NU` code is here; of MSBuild's ~790
documented codes only the couple of dozen that describe a *warning* are, because the rest are errors
that no `NoWarn` will ever hold and they would triple the size of the file for nothing.

The descriptions are clipped to a couple of sentences on purpose. This is read in a hover popup,
where the documentation link at the bottom is the answer for anyone who needs the whole page.
